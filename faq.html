Rules & FAQ

使用規則與常見問題

使用規則

  1. key 就是密碼不分享給其他組、不貼在群組、不上傳 GitHub、不寫進要交出去的檔案。外流的 key 會被停用。
  2. 用在學習與專題這是學校的教學設備，請用在課程、專題與學習相關的用途。
  3. 共用資源，互相禮讓大量處理資料時放慢速度，避開上課時間，先用少量資料測試。
  4. 誠實標示 AI 協助作業和專題中由 AI 產生的內容，請清楚標示，並說明你自己做了哪些判斷和修改。

常見問題

怎麼申請 API key？

請向資訊老師領取，一人一把。key 遺失或外流時請告訴老師，會停用舊的並換一把新的。

我的對話內容會被看到嗎？

閘道只記錄「哪一把 key、什麼時間、用了多少 tokens、成功或失敗」，用來管理用量與排除問題，不記錄你送出的問題和 AI 的回答內容。不過仍請不要送出個人敏感資料（身分證字號、密碼等），這是使用任何 AI 服務都該有的習慣。

為什麼有時候很慢？

叢集同時約可處理 6 個請求，超過就要排隊。我們實測 30 人同時發問時，最久要等約 2 分鐘才開始回答。另外，問題越難、reasoning_effort 越高，AI 思考越久。

回答是空白的？

通常是 max_tokens 設太小，額度全被「思考」用完了。拿掉 max_tokens 或設 500 以上。詳見快速開始。

回答常常是英文？

在 system prompt 寫明「用繁體中文回答」。它的思考過程（reasoning_content）通常是英文，這是正常的。

它和 ChatGPT 一樣嗎？

gpt-oss-120b 是 OpenAI 公開釋出的開源模型，和 ChatGPT 是同一家公司做的，但不是同一個模型。它的知識有截止日期，也不會上網查資料；需要最新資訊時，請自己把資料放進提示詞（見 RAG）。

可以用在其他語言或工具嗎？

可以。任何支援「OpenAI 相容 API」的工具都能用，只要把網址設成 http://192.168.16.131:8080/v1、模型設成 gpt-oss-120b。JavaScript 可以用 openai npm 套件，用法幾乎一樣。

叢集好像掛了？

在瀏覽器打開 http://192.168.16.131:8080/health：

  • "ok": true：叢集正常，問題可能出在你的程式或 key。
  • "ok": false 或打不開：叢集可能在重開機或維護中，請稍後再試，持續發生請通知資訊老師。

我想研究叢集本身，可以嗎？

非常歡迎。請看 研究題目建議，並和資訊老師討論需要的權限與資料。
