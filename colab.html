在 Colab 裡使用校內 LLM

Colab 的程式不是在你的電腦上執行，而是在 Google 的雲端主機上。雲端主機連不到校內網路的 192.168.16.131，所以 Colab 要改用另一個網址。

Colab 專用網址開通中。 老師正在設定校外連線用的網址，開通後會更新這一頁。在那之前，請先用 PyCharm 或電腦上的 Python 練習。

為什麼網址不一樣？

你在哪裡寫程式程式在哪裡執行要用的網址
PyCharm、Thonny、終端機你的電腦（校內網路）http://192.168.16.131:8080/v1
Google ColabGoogle 的雲端主機Colab 專用網址（開通中）

步驟 1：把 key 存進 Colab Secrets

Colab 有一個專門放密碼的地方，key 存在那裡，分享筆記本時別人看不到：

  1. 打開 Secrets點 Colab 左側工具列的 🔑 鑰匙圖示。
  2. 新增 secret按「Add new secret」，Name 填 EXO_API_KEY，Value 貼上老師給你的 key。
  3. 開啟存取把「Notebook access」開關打開。

步驟 2：安裝套件並連線

!pip install -q openai
from google.colab import userdata
from openai import OpenAI

client = OpenAI(
    base_url="（Colab 專用網址，開通後公布）",
    api_key=userdata.get("EXO_API_KEY"),
)

response = client.chat.completions.create(
    model="gpt-oss-120b",
    messages=[{"role": "user", "content": "用一句話介紹 Colab"}],
)
print(response.choices[0].message.content)

之後的寫法和 快速開始完全一樣：串流、system prompt、多輪對話、JSON 輸出都能直接用。

分享筆記本前檢查一次。 用 Secrets 存的 key 不會跟著筆記本被分享出去，但如果你曾經把 key 直接寫在程式格裡，記得刪掉，並檢查輸出結果裡有沒有印出 key。
