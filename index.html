什麼是 EXO？

EXO 是一套開源的「分散式推論」軟體：它把一個大型語言模型（LLM）切成好幾段，分給好幾台電腦一起算。就像一本太厚、一個人搬不動的書，拆成三冊由三個人一起搬。

大型語言模型的參數必須全部放進記憶體才能運作。gpt-oss-120b 有 1200 億個參數，壓縮後約 63 GB；我們每台 Mac mini 只有 48～64 GB 記憶體，單台放不下。EXO 把模型的 36 層切成三段，每台負責一段，再用 Thunderbolt 線把運算結果接力傳下去。

為什麼要在校內架 LLM？

01 · 免費

不用付 API 費用

雲端 AI 依用量計費，程式寫錯跑成迴圈，一晚就可能燒掉幾千元。在這裡練習，一毛都不用花。

02 · 隱私

資料不離開學校

你送出的問題、上傳的資料只在校內三台電腦間處理，不會傳到任何雲端公司。

03 · 業界標準

OpenAI 相容 API

用的是和 ChatGPT API 一模一樣的寫法。在這裡學會，將來換成任何雲端服務都只要改一行網址。

04 · 夠大

1200 億參數

gpt-oss-120b 會「先思考再回答」，寫程式、解數學、做推理都明顯比一般小模型強。

05 · 看得見

AI 不再是黑盒子

模型就在你眼前的三台機器上跑。分層、記憶體、網路、耗電都能實際觀察，甚至拿來當科展題目。

06 · 可擴充

加一台就更強

再加一台 Mac，叢集就能跑更大的模型。這正是現在 AI 資料中心的運作方式，只是縮小成教室版。

為什麼大模型反而快？ gpt-oss-120b 是「混合專家」（MoE）架構：1200 億參數裡，每產生一個字只會用到約 50 億個。我們用同一套設備測過 700 億參數的 Llama 3.3，單機每秒只有 5.8 tokens，gpt-oss-120b 快了 5 倍。

開始使用

  1. 向資訊老師領取 API key一人一把。key 就像密碼，不要分享，也不要上傳到 GitHub。
  2. 連上校內網路叢集只在校內網路開放。Google Colab 在雲端，連不到叢集，原因見 Colab 與 Jupyter。
  3. 照著「快速開始」寫第一支程式快速開始只要 5 分鐘。用 PyCharm 的同學接著看 PyCharm 設定。
